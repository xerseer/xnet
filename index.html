xnet

A fully typed and validated remote networking wrapper module for Roblox to make your life easier, and your code cleaner.

Creator Store ↗

Quick start

local xnet = require(game.ReplicatedStorage.xnet)

return xnet:Namespace({
	Chat = xnet:Channel("Across", xnet.string({ maxLength = 200 })),
	GetCoins = xnet:Channel("Across", xnet.nothing(), xnet.integer({ min = 0 })),
	Hit = xnet:Channel("Across", xnet.struct({
		target = xnet.character(),
		damage = xnet.range(0, 100),
	}), nil, { rateLimit = 10 }),
	Toast = xnet:Channel("Same", xnet.string()),
})
local Net = require(game.ReplicatedStorage.Net)

Net.Chat:ConnectFromClient(function(player, text)
	Net.Chat:SendToAllClients(`{player.Name}: {text}`)
end)

Net.GetCoins:ConnectFromClient(function(player)
	return coins[player] or 0
end)
local Net = require(game.ReplicatedStorage.Net)

Net.Chat:ConnectFromServer(function(line)
	print(line)
end)

Net.Chat:SendToServer("hello")
local amount = Net.GetCoins:SendToServer() -- number

Receivers

The first argument to xnet:Channel says where messages go.

ReceiverGoesMethods
"Same"Stays on this side. No remote is made.Send, Connect
"Across"Server ↔ client over a remote.SendTo…, ConnectFrom…
"Both"Either way.All of them
 
xnet:Channel(receiver, input?, output?, options?)

Leave output out (or nil) for an event. Give it a schema to make a request that returns a value.

Channel methods

MethodRuns onDoes
:Send(data)same sideCalls this side's Connect handlers.
:Connect(fn)same sideListens for Send. fn(data)
:SendToServer(data)clientFires, or requests, the server.
:SendToClient(player, data)serverFires, or requests, one player.
:SendToAllClients(data)serverFires every player. As a request, returns { [Player]: result }.
:ConnectFromClient(fn)serverHandles client messages. fn(player, data)
:ConnectFromServer(fn)clientHandles server messages. fn(data)
:DisconnectAll()eitherRemoves every handler on the channel.

Every :Connect() returns a connection:

local connection = Net.Toast:Connect(function(text)
	print(text)
end)

Net.Toast:Send("Saved")
connection:Disconnect()

Requests

A channel with an output schema is a request. SendTo… yields until the other side's handler returns, and the reply is checked against output.

local Confirm = xnet:Channel("Across", xnet.string(), xnet.bool(), { timeout = 15 })

-- client
Net.Confirm:ConnectFromServer(function(question)
	return showDialog(question)
end)

-- server
local yes = Net.Confirm:SendToClient(player, "Trade 50 coins?")
  • A request channel takes one handler per side. A second Connect… errors.
  • A missing or failing handler replies nil, which is then checked like any other reply.
  • On a timeout or rejected reply, onRequestFailed decides what you get. See Configure.
  • Requests can't be unreliable.

Channel options

OptionTypeDoes
unreliablebooleanUses an UnreliableRemoteEvent. Events only, not Same.
rateLimitnumberMessages per second per player, checked on the server. Extra ones are dropped.
strictbooleanOverrides the global strict for this channel.
timeoutnumberRequest timeout in seconds for this channel.
middleware(player?, value) -> booleanRuns after validation. Return false to drop the message.
 
Move = xnet:Channel("Across", xnet.vector3(), nil, {
	unreliable = true,
	rateLimit = 30,
	middleware = function(player, position)
		return player ~= nil and player.Character ~= nil
	end,
})

Configure

Call xnet:Configure with the same settings on the server and the client, before xnet:Namespace.

xnet:Configure({
	timeout = 5,
	onRequestFailed = "nil",
	debug = game:GetService("RunService"):IsStudio(),
	onRateLimited = function(player, channelName)
		warn(player.Name, "is spamming", channelName)
	end,
})

Validation

Every value that crosses the network is parsed by its schema. Bad parts are replaced with the schema's fallback, and the whole list of problems is logged with paths.

xnet: 'Hit' event from Player1 had invalid data (cleaned):
  damage: 250 is above the maximum 100
  bonus: unexpected field (dropped)

With strict = true, an invalid message is dropped and no handler runs. Use it for anything a cheater could abuse.

Order on arrival: rate limit → schema → global middleware → channel middleware → handlers.

Schemas

The fallback is what an invalid value becomes when it's cleaned.

Values

SchemaTypeFallback / notes
bool()booleanfalse
number({ min?, max?, integer? })numberRejects NaN and inf. Clamps to min/max.
integer({ min?, max? })numberRounds non-integers.
range(min, max)numberClamps into range.
string({ maxLength? })string"". Truncates to maxLength bytes.
buffer({ maxSize? })bufferEmpty buffer.
vector3() vector2() cframe() color3()sameZero / identity / black. Must be finite.
numberRange() numberSequence() ray() dateTime()sameMust be finite where it applies.
player()Player?A Player still in the game.
character()Model?A Model that belongs to a player.
instance(className?)T?Checks IsA(className).
any()anyNo checks.
nothing()nilFor channels that send no data.

Choices

SchemaTypeFallback / notes
literal(value)TOnly value.
enum({ a = true, b = true })"a" | "b"First value, sorted. The list form {"a","b"} also works but types as string.
robloxEnum(Enum.Material)Enum.MaterialFirst item of the enum.
union(a, b, ...)A | BFirst schema that matches cleanly, in order. Otherwise a's fallback.

Collections

SchemaTypeFallback / notes
struct({ key = schema }){ key: T }Unknown fields are dropped.
array(schema, { minLength?, maxLength? }){ T }Extra items are cut off.
tuple(a, b, ...){ A | B }Fixed positions.
map(key, value, { maxEntries? }){ [K]: V }Invalid keys are dropped.
set(schema, { maxEntries? }){ [T]: true }Entries that aren't true are dropped.

Modifiers

SchemaTypeDoes
optional(schema)T?Allows nil.
default(schema, value)TUses value when missing or invalid, without logging.
refine(schema, check, message?)TAdds a custom check.
transform(schema, fn)TChanges the value after parsing, then checks it again.
 
local Item = xnet.struct({
	id = xnet.string({ maxLength = 32 }),
	rarity = xnet.enum({ common = true, rare = true, epic = true }),
	count = xnet.default(xnet.integer({ min = 1, max = 99 }), 1),
	tags = xnet.optional(xnet.set(xnet.string(), { maxEntries = 8 })),
	name = xnet.transform(xnet.string({ maxLength = 20 }), function(text: string)
		return string.lower(text)
	end),
	price = xnet.refine(xnet.number(), function(n) return n >= 0 end, "price can't be negative"),
})

Equip = xnet:Channel("Across", Item)

Typing tips

  • literal("idle") widens to string. Annotate it to keep the exact value: local idle: Types.Schema<"idle"> = xnet.literal("idle").
  • Use the keys form enum({ idle = true, run = true }) to get "idle" | "run".
  • Annotate the parameter in transform callbacks, like function(text: string). refine usually works without it.
  • Get a schema's value type with Types.ValueOf<typeof(schema)>.
